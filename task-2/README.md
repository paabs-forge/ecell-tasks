# E-Cell UIET KUK — Entrepreneurship Cell

> **Disclaimer:** This is a practice/recruitment task project created as part of the E-Cell UIET KUK club entrance process. It is **not an official website of E-Cell UIET KUK** and is intended solely as a design and development exercise.

## Overview

This project is a modern, responsive front-end landing page created as part of the E-Cell UIET KUK club entrance task.

The website redesign presents the E-Cell's purpose, entrepreneurial journey, activities, upcoming events, core team, and contact information through a responsive web interface.

The landing page also connects the Startup Pitch Competition CTA with the registration system developed as part of Task 1.

---

## Features

### Responsive Landing Page

- Responsive layout for desktop, tablet, and mobile screens.
- Responsive typography, spacing, grids, cards, navigation, and sections.
- Mobile navigation with a collapsible menu.
- Adaptive layouts for different viewport sizes.

### Hero Section

- E-Cell introduction and primary message.
- "Ideate · Innovate · Incubate" positioning.
- "Join Us" primary CTA.
- "Explore Events" CTA.
- Five-stage entrepreneurial journey displayed alongside the hero content.

### Entrepreneurial Journey

The website presents a five-stage journey:

1. **Ideate** — Find the problem
2. **Explore** — Understand the opportunity
3. **Build** — Make the idea testable
4. **Pitch** — Get challenged and refine
5. **Incubate** — Move toward implementation

### About Section

- Introduction to E-Cell UIET KUK.
- Information about the entrepreneurship ecosystem.
- UIET KUK visual representation.

### What We Do

The website presents the major areas through which E-Cell supports students, including:

- Ideation
- Innovation
- Incubation
- Mentorship
- Entrepreneurship-focused activities

### Events Section

- Upcoming and relevant E-Cell events.
- Event cards with supporting information.
- Startup Pitch Competition highlighted as an important event.
- "Coming Soon" indicators for events whose details are not currently available.
- Registration CTA connected to the Task 1 registration system.

### Task 1 Integration

Task 1 involved developing the registration system used for the Startup Pitch Competition.

The Task 2 landing page integrates the Task 1 registration system through the Startup Pitch Competition registration CTA.

### Team Section

- Core E-Cell team members.
- Team member names and roles.
- Responsive team cards.

### Contact Section

- E-Cell address and contact information.
- Social media links.
- Contact form with name, email, and message fields.
- Contact form interaction that opens the user's configured email client.

### Navigation

- Sticky navigation bar.
- Smooth scrolling between sections.
- Active navigation indication.
- Mobile navigation menu.
- "Join Us" CTA in the main navigation.

### Visual Design

- Dark visual theme.
- Orange accent colour.
- Responsive typography.
- Rounded cards and subtle borders.
- Hover interactions.
- Subtle gradients and visual treatments.
- Scroll-reveal animations.
